Maintain {{var_in_guild}} as a boolean: true only while the player is confirmed to be inside the adventurers' guild (冒険者ギルド / リーナの受付). Set it to true when the chat confirms the party has entered the guild (the narration shows them inside, or abyss_state scene.location becomes ギルド). Set it to false as soon as leaving is confirmed (e.g. 「ギルドを出る。」 or moving to another place). Mere mentions, plans or talk about the guild never change it. If unclear, keep the current value.
